## Audit dan perubahan

Source aktif 13 Agustus diaudit dan dipreservasi sebelum perubahan. Runtime lokal menunjukkan master 0, mapping 0, satu KB DRAFT dengan 5.432 pairs, antrean 100, cursor Januari 2023. Poll tersimpan terakhir PARTIAL: 100 terdeteksi/87 stabil/0 diproses/13 belum lengkap/87 gagal. Password proses dan Machine tersedia tetapi berbeda; pemeriksaan koneksi read-only dengan sumber Machine yang dipilih secara eksplisit berhasil. Kredensial tidak dicetak, disimpan, diganti atau disubstitusi aplikasi.

Pembacaan read-only MariaDB 10.4.32 menemukan 22.224 header dan 2.845 master aktif; tiga kasus pengguna terlihat dengan item reguler 4/5/2 dan racikan 0/0/4. Koneksi berhasil tidak berarti KB dapat digunakan. Tidak ada resep pasien yang dipaksa lulus skrining.

Smoke adapter final pada MariaDB aktual juga PASS secara read-only: jam server terbaca, keyset berjalan, ketiga snapshot terbaca dan konteks transaksi dilepas. Header view lama tetap UNVERIFIED/composition_complete=false. Bukti agregat saja: `qualification/mysql-adapter-readonly-smoke.json`.

Implementasi menambahkan lane resep terkini dan replay/reconciliation, checkpoint+inbox atomik, lock worker/proses, retry beralasan, event observasi immutable, dua pembacaan stabil minimal 2 detik, revisi/validasi/batal validasi, snapshot repeatable-read, outbox notifikasi dan pengiriman per hasil. Histori/cursor tidak direset. Crash setelah tampil sebelum SHOWN tersimpan masih bisa menyebabkan pengulangan; bukan exactly-once.

Sinkronisasi master hanya menambah PENDING_REVIEW, preservasi mapping/input manual, workbook mapping yang dapat dipreview. Sebanyak 5.432 pairs tetap DRAFT dan tidak diaktifkan otomatis. Notifikasi membedakan SERIOUS/CONTRAINDICATED dari warning CRITICAL lain; minor/moderate tetap ditangani. Konfirmasi tanpa interaksi hanya setelah validasi dengan komposisi FINAL terverifikasi, assessment lengkap dan tanpa issue/warning.

Monitor mulai tanpa klik setelah konfigurasi serta consent sah, tetap berjalan di tray. Keluar penuh berhenti; tidak ada service baru. Default consent=false dan polling=false dipertahankan. Silent/advisory/production gates tetap fail-closed; gate pengguna aktif, keadaan sumber terbaru dan koneksi diperiksa saat pengiriman.

## Installer

File: `e-MSS-Farmasi-RS-Setup-0.31.0-x64.exe`  
Ukuran: 64,525,454 byte  
SHA-256: **7B6AC7AACAA45ACD9ABB7A7BF43FAA14F8BA88E1B149E2698C6AF54EDFD82A3A**

Installer lama 0.30.0 tidak ditimpa dan hash ulang sesuai `C8DD773EB639CBEAAF663211905E0D883A6A0FA9FDE60A3CA878D768105B6CA2`.

Build memakai Python 3.13.15 yang diwajibkan, PyInstaller dan Inno Setup 6 portabel. Template/seed dibundel; konten dist diperiksa dan di-hash oleh qualifier. Qualification tidak berarti installer sudah dipasang pada clean-host RS. Health smoke binary memakai config/data terisolasi. Source desktop/audio sudah dijalankan; playback GUI dari binary terpasang dan persepsi manusia masih memerlukan UAT.

Catatan toolchain: pemanggilan Windows PowerShell 5 dari checker tidak dapat memuat Microsoft.PowerShell.Security, sehingga detail gate adalah NO_STATUS dan tetap FAIL. Pemeriksaan Get-AuthenticodeSignature langsung pada host menghasilkan NotSigned untuk kedua hash artefak (lihat `qualification/authenticode-direct.json`). Tidak ada perubahan execution policy, pemalsuan hasil atau bypass signature. Sebelum rilis bertanda tangan, perbaiki lingkungan pemuatan modul checker dan ulangi gate pada host sasaran. Inno Setup juga memberi warning lama admin-install + opsi userstartup; startup tetap unchecked.

WAV pilihan pengguna tetap byte-identik secara lokal, tanpa konversi/penggantian. **Tidak dibundel** karena penerapan lisensi Mixkit untuk redistribusi aplikasi belum dipastikan. Rincian dan tautan resmi ada di `AUDIO_PROVENANCE_20260827.md`; ini kehati-hatian distribusi, bukan pendapat hukum.
