# E-MAS Farmasi Clinical Icon Set

The SVG files in this folder are local, bundled vector adaptations based on
the Lucide icon design language. Lucide Icons are available under the MIT
License: https://lucide.dev/license . The assets are included locally and are
never requested from a network service at runtime.

Each file is restricted to a semantic clinical or operational function by
`emss.ui.icons`. Do not substitute emoji, decorative artwork, or unreviewed
external icon files in this registry.
