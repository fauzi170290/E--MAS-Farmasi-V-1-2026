A. Cek cepat saat Khanza terbuka

BACA-SAJA Fungsi: menemukan Java Khanza yang benar, pemilik proses, path runtime, dan status Java Access Bridge (JAB).

A1 — Status Khanza dan JAB
$khanza = Get-CimInstance Win32_Process |
  Where-Object {
    $_.Name -in 'java.exe','javaw.exe' -and
    $_.CommandLine -match '(?i)khanza\.jar'
  } |
  Select-Object -First 1

if (-not $khanza) {
  Write-Host 'KHANZA_TIDAK_DITEMUKAN. Buka Khanza dahulu.'
  return
}

$javaHome = Split-Path (Split-Path $khanza.ExecutablePath -Parent) -Parent
$jabSwitch = Join-Path $javaHome 'bin\jabswitch.exe'
$jabConfig = Join-Path $env:USERPROFILE '.accessibility.properties'
$owner = Invoke-CimMethod -InputObject $khanza -MethodName GetOwner
$jabEnabled = Test-Path $jabConfig -and (
  Get-Content $jabConfig -ErrorAction SilentlyContinue |
    Select-String -Pattern '^\s*assistive_technologies\s*=\s*.*AccessBridge' -Quiet
)

[PSCustomObject]@{
  Khanza_PID         = $khanza.ProcessId
  Java_Runtime       = $javaHome
  Java_Executable    = $khanza.ExecutablePath
  Khanza_Owner       = "$($owner.Domain)\$($owner.User)"
  PowerShell_User    = "$env:USERDOMAIN\$env:USERNAME"
  Jabswitch_Ada      = Test-Path $jabSwitch
  JAB_Aktif          = $jabEnabled
  Konfigurasi_JAB    = $jabConfig
  CommandLine        = $khanza.CommandLine
} | Format-List
HasilMakna / tindakan berikutnya
JAB_Aktif : TrueLanjut ke C atau D. Jangan menjalankan enable lagi.
JAB_Aktif : FalseLanjut ke B.
Jabswitch_Ada : FalseJangan salin DLL dari Java lain. Runtime Liberica yang dipakai Khanza perlu repair/install oleh IT.
KHANZA_TIDAK_DITEMUKANBuka Khanza dahulu, lalu ulangi. Jika masih gagal, gunakan A2.
A2 — Daftar proses Java bila Khanza tidak ditemukan
Get-CimInstance Win32_Process |
  Where-Object { $_.Name -in 'java.exe','javaw.exe' } |
  Select-Object ProcessId, ExecutablePath, CommandLine

B. Aktifkan JAB bila memang belum aktif

MENGUBAH KONFIGURASI PER-USER Fungsi: membuat konfigurasi agar JVM Khanza memuat Java Access Bridge saat mulai ulang. Ini tidak mengubah resep, database, source E‑MAS, atau installer.

Jangan paksa tutup melalui PowerShell. Tutup Khanza manual terlebih dahulu agar data operator tidak hilang.

B1. Pastikan Khanza sudah ditutup

B1 — Konfirmasi proses Khanza sudah berhenti
Get-CimInstance Win32_Process |
  Where-Object {
    $_.Name -in 'java.exe','javaw.exe' -and
    $_.CommandLine -match '(?i)khanza\.jar'
  } |
  Select-Object ProcessId, ExecutablePath, CommandLine

Output harus kosong. Bila masih ada PID, kembali ke Khanza dan tutup manual.

B2. Aktifkan untuk runtime x86 client yang sudah terverifikasi

B2 — Enable JAB Liberica 12 x86
$javaHome = 'C:\Program Files (x86)\BellSoft\LibericaJDK-12-32'
& "$javaHome\bin\jabswitch.exe" -enable

B3. Verifikasi hasil enable

B3 — Konfirmasi AccessBridge pada profil user
$jabConfig = Join-Path $env:USERPROFILE '.accessibility.properties'
Get-Content $jabConfig -ErrorAction Stop |
  Select-String -Pattern 'assistive_technologies|AccessBridge'

Output yang diharapkan: assistive_technologies=com.sun.java.accessibility.AccessBridge. Setelah itu buka ulang Khanza dan E‑MAS.

Jika file tidak ada atau output kosong: pastikan Khanza_Owner dan PowerShell_User pada A1 adalah user yang sama. jabswitch menyimpan konfigurasi per-user.

C. Verifikasi sesudah Khanza dibuka ulang

BACA-SAJA Fungsi: melihat window Khanza aktif dan modul yang terbaca. Daftar modul kosong tidak otomatis berarti gagal; bukti utama adalah E‑MAS dapat membaca resep.

C1 — Window dan modul Khanza
$khanza = Get-CimInstance Win32_Process |
  Where-Object {
    $_.Name -in 'java.exe','javaw.exe' -and
    $_.CommandLine -match '(?i)khanza\.jar'
  } |
  Select-Object -First 1

Get-Process -Id $khanza.ProcessId |
  Select-Object Id, ProcessName, SessionId, MainWindowHandle, MainWindowTitle, Responding, Path

Get-Process -Id $khanza.ProcessId -Module |
  Where-Object {
    $_.ModuleName -match '(?i)AccessBridge' -or
    $_.FileName -match '(?i)AccessBridge'
  } |
  Select-Object ModuleName, FileName

D. Khanza terhubung, tetapi resep tidak masuk antrean / popup

Makna penting: jika E‑MAS menunjukkan PRESCRIPTION_VIEW_NOT_FOUND, Tabel Obat: Belum terbaca, dan Jumlah Obat: 0, maka masalah terjadi sebelum antrean/popup/audio. E‑MAS sengaja fail-safe agar tidak memakai data pasien sebelumnya.

Setelah gagal, jangan pindah pasien lagi. Jalankan query ini.

D1 — Reason-code snapshot JAB terbaru
$log = 'C:\ProgramData\eMSSFarmasi\Logs\emss.log'

Get-Content $log -Tail 300 -ErrorAction Stop |
  Select-String -Pattern 'DESKTOP_SNAPSHOT=INCOMPLETE|DESKTOP_SNAPSHOT=STABLE|DESKTOP_BRIDGE_STATE|BRIDGE_MESSAGE_QUEUE_FULL'
ReasonArti
DETAIL_NOT_DETECTEDVariasi tampilan/detail resep Khanza belum dikenali.
DETAIL_CARE_ID_NOT_READABLENo. Rawat pada detail tidak terbaca.
QUEUE_IDENTITY_NOT_BOUNDAntrean dan detail belum dapat dipastikan resep yang sama.
NO_COMMITTED_ITEMSTabel ditemukan, namun obat/jumlah belum valid atau belum final.
CARE_SETTING_NOT_DETECTEDRalan/Ranap belum dapat ditentukan.
PATIENT_IDENTITY_AMBIGUOUSLebih dari satu identitas terbaca; E‑MAS berhenti demi keselamatan pasien.

Untuk analisis lanjutan, kirim hasil D1 + Salin Diagnosa E‑MAS + screenshot tabel obat Khanza yang sudah diburamkan (nama pasien, RM, No. Rawat, No. Resep).

E. Overlay muncul, tetapi popup tidak

Tes manual, tanpa query:

  1. Buka resep baru dan tetap di layar resep itu selama 20 detik.
  2. Catat kapan overlay muncul dan kapan popup muncul.
  3. Buka ulang resep yang sama tanpa perubahan.

Normal bila resep yang sama hanya memperbarui overlay tanpa mengulang popup/audio; E‑MAS mencegah duplikasi berdasarkan fingerprint. Jika resep baru tetap tidak masuk antrean setelah 20 detik, jalankan D1.

F. Cek kecepatan pembacaan

BACA-SAJA Fungsi: membedakan lambat pada JAB dari lambat pada antrean/popup.

F1 — Timing snapshot JAB
$log = 'C:\ProgramData\eMSSFarmasi\Logs\emss.log'

Get-Content $log -Tail 500 -ErrorAction Stop |
  Select-String -Pattern 'DESKTOP_SNAPSHOT=STABLE|DESKTOP_SNAPSHOT=INCOMPLETE' |
  Select-Object -Last 20
  • JAB_PAIR_MS tinggi: pembacaan accessibility tree Khanza yang lambat.
  • NODES tinggi: tampilan Khanza lebih kompleks.
  • Snapshot stabil cepat, popup terlambat: periksa antrean popup/deduplikasi, bukan JAB.
Jangan mengubah stabilisasi agar cepat. Dua pembacaan JAB identik adalah pelindung agar alert tidak tertukar ke resep/pasien sebelumnya.

G. Cek konfigurasi E‑MAS

BACA-SAJA Fungsi: melihat setting client tanpa mengubahnya.

G1 — Setting Desktop/JAB
$config = 'C:\ProgramData\eMSSFarmasi\config.toml'

Get-Content $config -ErrorAction Stop |
  Select-String -Pattern 'khanza_adapter|khanza_poll_interval_seconds|khanza_desktop_overlay_poc|khanza_stability'

Nilai normal: khanza_adapter = "desktop", khanza_desktop_overlay_poc = true, dan khanza_poll_interval_seconds = 1.

H. Popup muncul, tetapi audio tidak terdengar

BACA-SAJA Audio tidak memblokir pembacaan resep atau popup. Ini diagnosis terpisah.

H1 — Perangkat audio Windows
Get-CimInstance Win32_SoundDevice |
  Select-Object Name, Status, Manufacturer

Lalu di E‑MAS buka Suara Peringatan: periksa volume aplikasi dan file audio. Jangan menganggap audio sebagai penyebab resep tidak terbaca.

Urutan diagnosis aman

Khanza ditemukan → JAB aktif → snapshot resep stabil → antrean → popup → audio.

Panduan ini tidak mengubah source E‑MAS, bridge, database, KB DDI, atau installer.
