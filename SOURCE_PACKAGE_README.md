# Paket Sumber E-MAS Farmasi 1.0.21

Paket ini disiapkan untuk dibuat sebagai repository GitHub atau sebagai bahan
penyusunan panduan penggunaan. Isi paket hanya source code, dokumentasi,
migrasi, bridge native, template, seed, dan automated tests.

Tidak termasuk: installer/binary hasil build, output test, database lokal,
log, konfigurasi lokal, kredensial, virtual environment, atau toolchain.

Untuk GitHub: buat repository kosong, salin isi folder ini ke root repository,
lalu ikuti README.md. Jangan menambahkan config.toml atau file database lokal.
